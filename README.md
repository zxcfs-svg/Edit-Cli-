# edit

Минималистичный терминальный текстовый редактор в стиле nano на C++17.
UTF-8 из коробки, всплывающие уведомления, буфер обмена.

## Возможности

- UTF-8 (кириллица, европейские языки) — корректный курсор и редактирование
- Всплывающие уведомления (сохранение, поиск, замена)
- Копирование / вставка строк
- Поиск и замена по буферу
- Tab = 4 пробела
- Один файл, без зависимостей, POSIX (Linux/macOS)

## Горячие клавиши

| Клавиша | Действие       |
|---------|----------------|
| `^S`    | Сохранить      |
| `^X`    | Выход          |
| `^A`    | Выделить всё   |
| `^C`    | Копировать     |
| `^V`    | Вставить       |
| `^D`    | Очистить буфер |
| `^W`    | Поиск          |
| `^R`    | Замена         |
| `^G`    | Справка        |
| `^Y`    | Страница вверх |
| `^O`    | Страница вниз  |
| `Tab`   | 4 пробела      |

`^` = Ctrl.

## Сборка

```sh
make
./edit [file]
```

Установка:

```sh
sudo make install
```

## Требования

- Linux или macOS
- C++17 (g++ >= 7, clang++ >= 5)
- UTF-8 локаль (`LANG=...UTF-8`)
